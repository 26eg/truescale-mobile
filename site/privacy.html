隐私政策（Privacy Policy）

生效日期：2026-11-25 · 开发者：26eg

1. 我们收集哪些数据？

不收集任何数据。「真实尺寸 TrueScale Mobile」的所有功能均在您的本地浏览器中离线完成。我们不会收集、读取、上传、出售或与任何第三方共享您的浏览历史、访问网址、网页内容、账号信息、表单输入、屏幕截图或设备指纹。

2. 本地存储与卸载清理

插件仅使用浏览器内置的 chrome.storage.local 在本地保存以下功能性偏好设置：

  • 各显示器分档对应的物理尺寸校准比例（px/mm）与显示器备注名；
  • 用户手动添加的自定义机型参数；
  • 语言、主题（浅色/深色/跟随系统）、最近选择的设备方向与提示收起状态。

上述数据仅存于您的本机浏览器扩展存储目录中，不会通过云端同步，也不会发送至任何外部服务器。卸载插件时，浏览器会自动删除所有相关本地存储数据。

3. 权限使用说明

插件申请的每项 Manifest V3 权限均严格服务于单一核心目标——「在当前网页按 1:1 物理尺寸就地预览与截图」：

  • declarativeNetRequest：仅对您主动开启模拟器的当前标签页（按 tabId 严格隔离）应用临时移动端 User-Agent 与允许同页内嵌预览的响应头规则，退出模拟、刷新或关闭标签页时立即自动清除。
  • tabs：用于读取当前活动标签页的网址、重置浏览器缩放至 100%，并在您主动点击截图按钮时通过 captureVisibleTab 截取当前视口画面。
  • storage：仅用于在本地保存您的校准参数、自定义机型及界面偏好。
  • scripting：仅在您点击扩展图标开启预览时，将隔离开的 Shadow DOM 模拟器界面注入当前标签页。
  • <all_urls>：允许用户在任意访问的电商站点或普通网页上按 1:1 物理尺寸就地预览与截图。插件不会在后台静默扫描、抓取或上报任何网页数据。

4. 第三方链接

插件「支持开发者」弹窗中可能包含指向 GitHub、Ko-fi 或爱发电的静态外部超链接。只有当您主动点击这些链接时，浏览器才会在新标签页打开对应页面；插件本身不会加载任何外部脚本或跟踪像素。

Privacy Policy

Effective Date: 2026-11-25 · Developer: 26eg
100% Local Execution · Zero Data Collection · Zero Analytics · Zero Remote Code

1. Data Collection

TrueScale Mobile collects zero personal or browsing data. All preview rendering, physical screen calibration, touch simulation, and screenshot stitching run 100% locally inside your browser. We never collect, transmit, store remotely, or sell your browsing history, visited URLs, page contents, credentials, screenshots, or device fingerprints.

2. Local Storage

The extension uses only chrome.storage.local to persist functional preferences on your device:

  • Physical screen calibration ratios (px/mm) and optional display labels per monitor profile;
  • User-defined custom device presets;
  • UI language, color theme, last selected device orientation, and dismissed tips state.

This data never leaves your device, is not synced externally, and is automatically deleted by the browser when the extension is uninstalled.

3. Permissions Justification

Every Manifest V3 permission requested by TrueScale Mobile is strictly limited to its single purpose — previewing and capturing web pages at true 1:1 physical size:

  • declarativeNetRequest: Applies tab-scoped (tabIds: [tabId]) session rules only for the active simulated tab to emulate mobile User-Agent headers and allow in-place iframe framing. Rules are automatically cleared when exiting simulation, reloading the top page, or closing the tab.
  • tabs: Reads the active tab URL/state, resets zoom to 100% during 1:1 calibration accuracy, and captures screenshots via chrome.tabs.captureVisibleTab only when explicitly triggered by the user.
  • storage: Stores monitor calibration parameters, custom devices, and UI preferences locally via chrome.storage.local.
  • scripting: Injects the isolated Shadow DOM simulator UI into the active tab only when the user clicks the extension icon.
  • <all_urls>: Enables users to preview and capture any website they visit at true 1:1 physical dimensions. No background scraping, tracking, or network exfiltration ever occurs.

4. Third-Party Links

The optional “Support the Developer” modal contains static external hyperlinks (such as GitHub, Ko-fi, or Afdian). External sites are opened only when you explicitly click a link; no third-party SDKs, trackers, or remote scripts are bundled or executed.
