# 真实尺寸 TrueScale Mobile

在桌面浏览器上以 **1:1 真实物理尺寸（毫米/厘米）** 就地预览移动端与平板网页效果的 Chromium Manifest V3 扩展程序，专为跨境电商运营、设计师、产品经理与前端开发者打造。

> 完整遵循 Chrome Web Store 与紫鸟浏览器生态中心 Manifest V3 安全与隔离规范：100% 纯本地运行、零数据采集、零远程脚本、零高危权限。

---

## 核心特性

1. **真实尺寸预览 + 左右自适应可折叠抽屉 + 功能导览浮层**
   - 顶栏支持 **「真实尺寸」**、**「100% 高清」**、**「适配窗口」** 一键切换，下拉菜单居中对齐且层级高于侧边栏；机身模拟区居中且上下无文字干扰，地址栏不展示冗余浏览器品牌标签。
   - **左侧 `Tips` 抽屉**统一收纳未校准提示（通俗解释浏览器为何需要 10 秒一次性校准）、视图模式提示、常驻「真实尺寸 / 适配窗口」清晰度说明（*为什么预览画面不清晰？*）及可关闭的交互与快捷操作提示；**右侧自适应宽度参数卡**（单行无强制换行）展示机型、物理毫米、CSS 视口与 Scale；**模拟区右侧紧邻悬浮快捷操作栏（`QuickNavDock`）**提供 **后退 / 前进 / 刷新手机视图 / 回到顶部 / 去往底部** 五合一操作，顺手触达且截屏时自动隐藏。左右抽屉基于舞台区域相对定位，顶栏在窄窗口下折行 2–3 排也不会遮挡卡片，并自动折叠避让。
   - 首次安装打开或设置中点击 **「初始化插件」** 重置后，在顶部菜单栏下方优先弹出毛玻璃 **「功能导览」** 浮层（未校准时贴心解释校准原因并引导校准，已完成校准后自动隐藏底部引导按钮）；日常可随时点击顶栏 `?` 按钮重开；在系统页/商店等不支持页面上图标自动变灰并弹出友好提示弹窗。
2. **自适应宽窗口的多模式左基准游标校准（按显示器自动分档保存）**
   - 校准弹框宽度随浏览器窗口自适应缩放，Tab 顺序按使用频率依次为 **标准卡片对齐 → 真机对齐 → 自定义对齐 → 测量正方形边长 → 屏幕尺寸速选**；前 3 项游标统一以 `150 CSS px` 为最小宽度且与全轨道等宽拖动不溢出：
   - **标准卡片对齐（推荐）**：基于 **ISO/IEC 7810 ID-1 国际标准**（`85.60 × 53.98 mm`）配备淡色静态横向卡片方向示意，仅右侧蓝色虚线随手柄全轨道水平拖动（固定高度，上下线与弹框不跳动），突出「线框刚刚包裹住卡片边缘为最佳」。
   - **真机对齐**：机型选项与全局可选列表完全同步（含手机、平板及自定义机型），支持「短边 / 长边」无干扰切换。
   - **自定义对齐**：输入任意已知物体的正整数毫米长度（`20–400 mm`），右侧内置 **3×3 便利贴（76mm）、国际护照长边（125mm）、A5 纸短边（148mm）、A4 纸短边（210mm）、Letter 纸短边（216mm）、A4 纸长边（297mm）** 等日常手边常见标准尺寸快捷填入。
   - **测量正方形边长**：测量 200px 基准框实际物理边长（正整数 `20–150 mm`）。
   - **屏幕尺寸速选** + **红色准确度提醒** + **顶部待保存实时预览与底部当前生效配置档区分** + **多显示器配置档智能折叠（多屏自动展开）**。
3. **2026 全球热门去重 Top 10 机型（平板默认横屏）+ 安全区参考线**
   - 覆盖 iPhone 17、iPhone 17 Pro Max、Galaxy S26 Ultra、iPhone 17e、iPhone 16、Galaxy A17 5G、Galaxy S26、Google Pixel 10、iPad (11th Gen)、iPad mini (7th Gen) 与自定义设备；选择平板时自动默认进入 **横屏** 视图，切换手机恢复 **竖屏**。
   - 顶部定制向下展开的无障碍 `DeviceSelector`，精确还原各机型边框与前置摄像头位置，并支持可选开启 **「安全区参考线」**。
4. **点击图标直接就地变身 + 真实触摸体验 + 浏览器刷新自动还原**
   - 去除 Popup 弹窗以避免浏览器权限提示干扰：点击扩展图标直接在当前网页就地切换模拟，启动前自动将缩放重置为 100%，通过 Shadow DOM 隔离渲染。
   - 用户在浏览器触发刷新（`Ctrl+R` / `F5` / 浏览器刷新按钮）时自动取消模拟并清理网络规则；预览内注入触摸环境模拟（`navigator.maxTouchPoints = 5`、`ontouchstart`、`(pointer: coarse)`）与圆点触控惯性手势桥接。
5. **高分辨率长短截屏 & 便捷标注工作室（自动滚动长图预览 + 所见即所得写字）**
   - 菜单提供 **「截图」**、**「截图（带壳）」**、**「长截图」**、**「长截图（带壳）」**，默认 `≥ 2×` 高清缩放写入 `pHYs` DPI，长截图末尾采用渐进重叠舞台扫屏防止断层留白，顶部采用醒目白底进度条。
   - 截屏后默认进入纯净预览模式，**长截图自动上下往复匀速滚动预览**（鼠标悬停暂停）；点击左上角 **「编辑」** 开启双行上下文工具条，笔画粗细、字号与色卡紧贴工具条下方；支持框选/圆圈/箭头/画笔/马赛克/序号拖拽移位、马赛克虚线选框及 **点击画布即原位行内写字**，支持 `PNG`/`WEBP`/`JPG` 导出与一键复制剪贴板。
6. **联合国 6 种官方语言 + RTL 自适应、无障碍支持 & 零污染隔离**
   - 原生支持 **简体中文、English、العربية（自动 RTL）、Français、Русский、Español**，全模态弹窗均支持 `Tab` 焦点陷阱、`Escape` 关闭与焦点回退；提供浅/深色及跟随系统主题。
   - `declarativeNetRequest` 会话规则严格按 `tabIds` 隔离，精准区分 iframe 内部刷新与顶层页面刷新，绝不干扰正常网页或跨境店铺标签页指纹。

## 本地开发与构建

> 请在项目目录 `truescale-mobile/` 内使用局部 `node_modules/` 构建，切勿全局安装依赖。

```bash
cd truescale-mobile
npm install
npm run test       # 运行单元测试
npm run typecheck  # TypeScript 类型检查
npm run build      # 生成 MV3 产物到 dist/
```

构建完成后，打开 Chrome / Edge / 紫鸟浏览器的扩展管理页（`chrome://extensions/`）：
1. 开启右上角 **开发者模式**；
2. 点击 **加载已解压的扩展程序**；
3. 选择本项目的 `dist/` 目录即可立即体验。

## 赞赏入口配置

赞助入口配置在 [src/config/sponsor.ts](./src/config/sponsor.ts)：
- `enabled`: 默认 `true`；若提交环境禁止外链，可改为 `false` 一键隐藏。
- `buyMeACoffeeUrl` / `kofiUrl` / `afdianUrl`: 填入外部主页链接（纯 `<a>` 外链打开，无任何远程 JS）。
- `wechatQrPath` / `alipayQrPath`: 可将静态收款码放在 `public/sponsor/` 后填写相对路径（如 `./sponsor/wechat.png`）。

## Chrome Web Store & 紫鸟上架核查清单

- [x] `manifest_version: 3`，纯本地静态打包，无远程代码或 `eval`。
- [x] 最小必要权限集：`declarativeNetRequest`、`tabs`、`storage`、`scripting`（+ `<all_urls>` 用于无弹窗截图）；不申请 `debugger`、`management`、`cookies`。
